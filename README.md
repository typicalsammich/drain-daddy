# The Drain Daddy website redesign

Static multi-page prototype built for Vercel/GitHub.

## Included
- 12 service pages
- 10 unique service-area pages
- Maintenance plan
- Offers/coupons
- About/contact
- 8 blog posts
- Responsive mobile navigation and sticky mobile call CTA
- Matching teal/black custom cursor and scrollbar
- LocalBusiness/Plumber schema on home page
- sitemap.xml + robots.txt
